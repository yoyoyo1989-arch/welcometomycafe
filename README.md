# Golden Hour Café

Landing page for a three-outlet café in Singapore. Each version lives in its own folder, so older versions stay available.

| Version | Folder | Notes |
| --- | --- | --- |
| **v1.0** (latest) | [`v1.0/`](v1.0/) | First release: cinematic three-slide hero, outlet search (outlet, date, time, order type), three outlet pages with an Order ahead card. |

To view a version, open its `index.html` in a browser. See the README inside each folder for details and how to customise it.
